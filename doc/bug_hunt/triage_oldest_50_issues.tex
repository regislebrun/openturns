\section{Introduction and method}

This report classifies the 50 oldest \emph{open} issues of the
\href{https://github.com/openturns/openturns/issues}{openturns GitHub repository},
ranging from issue \#998 (January 2019) to issue \#1585 (September 2020).
Each issue body was read from the GitHub API; for ambiguous cases the full
comment threads were also reviewed and cross-checked against the current
source tree.

Each issue is assigned:
\begin{itemize}[noitemsep]
  \item a \textbf{category}: \emph{actual bug}, \emph{feature request}, or
        \emph{other} (documentation work, usage questions, duplicates);
  \item an \textbf{effort estimate}: \emph{easy} (contained change, at most a
        few files plus a test), \emph{medium} (single subsystem, needs design or
        broad but mechanical edits), \emph{hard} (new algorithms, API-wide
        refactors, platform-specific debugging), or \emph{no more valid}
        (stale, duplicate, support-only, or already superseded in master).
\end{itemize}

Category assignment follows the \emph{content} of the report rather than its
GitHub labels, which proved unreliable: several items labelled
\texttt{enhancement} describe genuine misbehaviours, while some items labelled
\texttt{doc} hide behavioural questions.

\section{Category analysis}

\subsection{Actual bugs (8 issues)}

\begin{description}
  \item[\#1231 -- Cannot save NumericalPointWithDescriptionCollection (no longer valid).]
        Uses pre-1.14 API names that no longer exist; not reproducible against
        any supported version. Should simply be closed after a quick sanity check.
  \item[\#1242 -- Circular dependency of ContinuousDistribution (hard).]
        Design flaw acknowledged by maintainers: remove the
        \texttt{ContinuousDistribution}/\texttt{DiscreteDistribution} layers.
        Touches the whole distribution hierarchy.
  \item[\#1244 -- Performance of OrthonormalizationAlgorithm (hard).]
        Numerical robustness/performance of recurrence-coefficient computation
        for extreme parameters; requires algorithmic expertise.
  \item[\#1245 -- Wrong comparison operator for interface classes (medium).]
        \texttt{ot.SobolSequence(2) == ot.HaltonSequence(2)} returns true because
        interface \texttt{operator==} compares only the top-level implementation
        type. Fix requires virtual dispatch in several hierarchies.
  \item[\#1250 -- Iso-probabilistic transformation parameters (hard).]
        Parameter reporting of marginal/copula transformations is inconsistent;
        needed for FORM sensitivities, so changes must be made carefully.
  \item[\#1355 -- Multiprocessing on Windows/Anaconda (hard).]
        Output printed once per worker with \texttt{n\_cpu > 1}; Windows-specific
        process/spawn semantics of \texttt{PythonFunction}; hard to reproduce
        and debug outside Windows.
  \item[\#1489 -- Mixture with Dirac does not draw its PDF (medium).]
        The discussion concludes that mixed distributions should render their
        atoms as arrows whose height relates to the dominant density mode;
        requires drawing-machinery work.
  \item[\#1585 -- KS fitting test p-value random (no longer valid).]
        Declared invalid (Monte-Carlo p-value by design). The follow-up action
        item (raise \texttt{FittingTest-KolmogorovSamplingSize}) has meanwhile
        been superseded in master by an adaptive Lilliefors scheme
        (\texttt{FittingTest-LillieforsMinimumSamplingSize},
        \texttt{...MaximumSamplingSize}, \texttt{...Precision}). Close as
        resolved/superseded.
\end{description}

\subsection{Feature requests (25 issues)}

Hard items are substantial algorithmic or API-wide projects: SRC confidence
bounds (\#1056), analytical kriging gradients (\#1225), kernel-smoothing
boundary specification (\#1227), Anderson-Darling for non-gaussian laws
(\#1237), semantic distribution equality (\#1246), moving draw methods to
result objects (\#1256), a storage backend for HistoryStrategy (\#1262),
PythonCovarianceModel (\#1320), discrete/continuous decomposition (\#1325),
symbolic distribution arithmetics (\#1445).

Easy, well-contained additions:
\begin{itemize}[noitemsep]
  \item \#1583 convenience axis-bound setters for Graph
        (\texttt{setXMin}/\texttt{setXMax}/\texttt{setYMin}/\texttt{setYMax});
  \item \#1424 \texttt{ProcessSample::split}, mirroring \texttt{Sample::split};
  \item \#1363 proper y-axis labelling when plotting SRC indices;
  \item \#1357 QQ-plot point style so outliers remain visible;
  \item \#1243 constructor consistency for
        UserDefinedStationaryCovarianceModel;
  \item \#1479 flattening/type checks in CompositeDistribution constructors.
\end{itemize}

\subsection{Other: documentation, questions, duplicates (17 issues)}

Eight easy documentation tasks (\#1077 kwargs ambiguity in ctor docstrings,

\section{Action plan for the easy fixes}

The following easy code fixes were selected to start with, ordered by value:
\begin{enumerate}[noitemsep]
  \item \textbf{\#1583} Graph: add \texttt{setXMin}/\texttt{setXMax}/%
        \texttt{setYMin}/\texttt{setYMax} implemented on top of
        \texttt{setBoundingBox}, switching off automatic bounding box;
        document them; add a test.
  \item \textbf{\#1424} ProcessSample: add \texttt{split(index)} mirroring
        \texttt{Sample::split}; add a test.
  \item \textbf{\#1363} SobolIndicesAlgorithm: allow a dedicated y-axis label
        so SRC indices are no longer plotted as ``correlation coefficient''.
  \item \textbf{\#1410} SphericalModel help page: document that positive
        definiteness is guaranteed only for spatial dimension $\leq 3$, with
        the Stein (1999) reference.
\end{enumerate}
Remaining easy items (mostly examples/docstrings) can then be processed in
batches; the two invalid bug reports should be closed upstream.
